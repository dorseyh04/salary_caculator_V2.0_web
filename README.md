# 康乃尔薪酬核算系统 V2.0 (Web 版)

> 基于《2026 年滨州康乃尔经营薪酬考核方案 V2.0》（2026 年 5 月 1 日起执行）的业务人员月度薪酬自动核算系统。

## ✨ 核心能力

- 🔢 **一键核算** — 上传 2 份 Excel + 录入少量人工字段，全员薪酬自动算清
- 📋 **严格按规** — 全部公式与系数依据 PRD v6.0，可在 `docs/PRD_v6.0.md` 中查阅
- 🔍 **逐笔可追溯** — 每个业务员的销售提成、溢价提成、贸易提成都展示完整推演过程
- 💾 **居间单价持久化** — 客户级居间单价跨会话自动保留（localStorage）
- 📤 **多格式导出** — CSV（汇总表，Excel 直开不乱码）+ Markdown（完整报告）
- ⚠️ **异常预警** — 基价缺失、单位换算失败、订单不匹配等问题集中展示
- 🔒 **纯前端** — 所有计算在浏览器内完成，业务数据不上传任何服务器

## 🚀 快速开始

```bash

pnpm install

pnpm dev

# 3. 浏览器访问

```

## 📖 使用流程

应用是 4 步向导式工作流：

### 步骤 1 — 上传文件

需要上传 2 份 Excel：

| 文件 | 必含 Sheet | 说明 |
|------|-----------|------|
| 回款明细表 | `回款明细`（24 列）+ `基价表`（4 列） | 当月所有回款订单 + 物料基价 |
| 绩效考核表 | `汇总表` 或 `绩效` | 当月业绩完成率、绩效分、抵扣总额 |

> 系统兼容绩效考核表的两种格式：6 列（无抵扣项）和 7 列（含抵扣项）。

### 步骤 2 — 确认 / 修改参数

6 个 Tab 配置：

1. **工资基数** — 基本工资 + 绩效工资基数（默认从绩效表读取，可逐人调整）
2. **抵扣项目** — 当月抵扣项目总额（含运输费、差旅费、招待费、样品费）
3. **居间单价** — 客户级溢价提成扣除（自动持久化到本地浏览器）
4. **负毛利订单** — 录入订单编号，按 0.25% 计提（覆盖产品线系数）
5. **贸易毛利** — T 列="贸易"的订单逐笔录入毛利金额与品类
6. **活跃度系数** — 按售达方展示并允许覆盖（默认从 X 列读取）

### 步骤 3 — 一键核算

点击"开始核算"即可。

### 步骤 4 — 查看结果

5 个报告视图：

- **薪酬汇总** — 一表概览全员，支持 CSV / Markdown 导出
- **交叉验证** — 全部收款 = 常规 + 贸易 + 剔除（万元单位）
- **参数总览** — 所有生效系数与人员配置一览
- **逐人详细** — 展开每人查看完整推演（绩效工资公式、销售提成加权过程、逐笔订单明细、贸易订单明细）
- **异常预警** — 集中展示数据问题

## 🧮 核心公式

```
月度薪酬 = 基本工资 + 绩效工资 + 销售提成 + 溢价提成 + 贸易业务提成

绩效工资 = (80% × min(完成率, 100%) + 20% × 绩效分) × 绩效工资基数

逐笔销售提成 = min(出厂售价, 基价) × 核定公斤 × 提成系数 × 活跃度系数
其中 出厂售价 = (收款金额 - 运费单价 × 核定公斤) ÷ 核定公斤

最终销售提成 = Σ逐笔销售提成 - 抵扣总额 × 加权平均提成系数
（结果为负时取 0；加权平均提成系数 = Σ逐笔销售提成 / Σ逐笔提成基数）

逐笔溢价提成 = (出厂售价 - 居间单价 - 基价) × 核定公斤 × 溢价系数
（仅在 出厂售价 - 居间单价 > 基价 时计算；溢价系数按溢价率 0/15/20/30% 分档）

逐笔贸易提成 = 用户录入毛利 × 品类提成比例
（熔喷料 40% / 母粒 30% / 无纺布 20%）
```

## 📊 提成系数表

### 销售提成（按产品线）

| 产品线 | 提成系数 |
|--------|---------|
| 普通个体防护 | 0.4% |
| 高端个体防护 / 工业吸附 / 液滤-电驻极 / 空滤 / 生活擦拭 | 0.6% |
| 耐高温材料 | 0.8% |
| 透气弹性材料 | 1% |
| 副牌 | 0.4%（最低档兜底） |
| 负毛利订单 | 0.25%（覆盖产品线） |

### 溢价提成（按溢价率）

| 溢价率 | 系数 |
|--------|------|
| ≤ 0 | 0 |
| 0 ~ 5% | 0.15 |
| 5% ~ 10% | 0.20 |
| > 10% | 0.30 |

### 提成活跃度（按客户合作时长）

| 合作时长 | 系数 |
|---------|------|
| 1～12 月 | 1 |
| 13～24 月 | 0.8 |
| 25～36 月 | 0.7 |
| 37～48 月 | 0.6 |
| 49 月及以上 | 0.5 |

> 仅作用于销售提成，溢价提成不适用。

## 🔐 数据安全

- **零上传** — 所有 Excel 解析、计算、报告生成均在浏览器内本地完成
- **零依赖外部 API** — 应用本身没有任何后端通信
- **localStorage 仅存居间单价** — 不存储任何业务数据或个人信息
- **建议** — 不要将真实业务数据提交到公开仓库（已在 `.gitignore` 中排除 `*.xlsx`）

## 📝 业务规则修改

修改提成系数、新增产品线、调整公式：

1. 修改 `components/SalaryApp.jsx` 顶部的常量定义（`PRODUCT_LINE_RATES`、`TRADE_RATES` 等）
2. 同步更新 `docs/PRD_v6.0.md`
3. 用真实 Excel 回归测试
